# Todo List Application

A simple Todo List application built with Spring Boot.

## Requirements

- Java 17 (OpenJDK)
- Gradle
- PostgreSQL

## Project Setup

1. **Clone the repository:**

   ```bash
   git clone <repository-url>
   cd todo-list
   
## Build the project 

   ./gradlew build
   
## Accessing the application:
